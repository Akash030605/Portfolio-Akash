
# Akash Sharma — Portfolio

A full-screen, interactive portfolio hero built with React, TypeScript, Vite, and Tailwind CSS. Features a mouse-scrubbed background video, a typewriter intro, and a minimal creative-agency aesthetic.

## ✨ Features

- **Mouse-scrubbed background video** — scrub forward/backward by moving your cursor horizontally. No autoplay, fully user-driven.
- **Typewriter intro** — a custom `useTypewriter` hook reveals the greeting character by character with a blinking cursor.
- **Blurred intro label** — a soft-focus "meet A.R.I.A" line that sits behind the main copy.
- **Animated action pills** — fade-in + slide-up CTAs that appear 400ms after load, independent of the typing animation.
- **Copy-to-clipboard email** — one click copies `hello@mainframe.co` to your clipboard.
- **Responsive navbar** — desktop links and CTA, plus a mobile hamburger with an animated overlay menu.
- **Avatar placeholder** — ready to swap in a real face image.

---

## 🛠 Tech Stack

| Layer | Tech |
|---|---|
| Framework | React + TypeScript |
| Build Tool | Vite |
| Styling | Tailwind CSS |
| Fonts | Helvetica Now Display (heading + body) |
| Icons | Inline SVG (no icon library) |

No UI libraries. No animation libraries. Everything is hand-rolled.
